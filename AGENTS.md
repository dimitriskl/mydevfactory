# MyDevFactory repository instructions

- Update the release notes at the top of `README.md` in every change. Add a short bullet explaining the change under the version that will ship it. Put pending changes under a versioned `(unreleased)` heading above the latest release notes.
- Keep the first line of `README.md` labeled with the latest installable version. When releasing, align it with `VERSION`, the skill metadata, the changelog and the pinned installer commands. Follow [Contributing](CONTRIBUTING.md#changing-pins-and-releasing) for release verification.
